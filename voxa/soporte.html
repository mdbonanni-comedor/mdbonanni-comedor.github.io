Preguntas frecuentes

¿VOXA Player trae canales?

No. Es solo un reproductor: tenés que cargar tu propia lista M3U. Para probarlo, en la primera pantalla elegí "Probar con la lista de demostración".

Un canal no se ve

Probá ese canal en otro equipo: si tampoco anda, el problema es del proveedor de la lista. Algunos formatos de video no son compatibles con todos los televisores.

Los subtítulos con IA no aparecen

Necesitás una clave de API de un proveedor de IA (Ajustes → Claves API para subtítulos). Algunos canales no permiten separar el audio; en ese caso la app avisa y sigue sin traducción.

FAQ

Does VOXA Player include channels?

No. It is only a player: you need to add your own M3U playlist. To try it, choose "Try the demo playlist" on the first screen.

A channel doesn't play

Try that channel on another device: if it fails there too, it's a provider issue. Some video formats are not supported by every TV.

AI subtitles don't show

You need an API key from an AI provider (Settings → Subtitle API keys). Some channels don't allow separating the audio; the app will tell you and keep playing without translation.
